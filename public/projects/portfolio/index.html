Overview

This site. Built with Hugo, custom-designed from scratch, deployed on Cloudflare Pages. Runs 24/7 for free with no server.

Stack

  • Hugo — static site generator, markdown content
  • Cloudflare Pages — global CDN deployment, zero downtime
  • Custom HTML/CSS layouts — no themes, fully bespoke design
  • Dark mode — preference persisted via localStorage

Design

Cormorant Garamond serif paired with DM Mono for labels. Warm cream palette with gold accents. Fully responsive.
